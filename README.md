# Snake Game

Це браузерна версія класичної гри Snake з адаптивним інтерфейсом та налаштуваннями.

## Особливості

- 10x10 (або інший розмір) ігрове поле
- Керування стрілками на клавіатурі та свайпами на мобільних пристроях
- Налаштування кольору змійки
- Налаштування UI теми та кольору дошки
- Налаштування швидкості гри та розміру дошки
- Лічильник поточного результату, кращого рахунку та статистики
- Збереження прогресу в `localStorage`
- Вимкнення прокрутки сторінки стрілками під час гри
- Множник очок, що зростає після кожного з’їденого фрукту

## Файли

- `index.html` — основний файл гри
- `README.md` — цей опис

## Як запустити

1. Відкрийте `index.html` у браузері.
2. Натисніть кнопку `Play`.
3. Керуйте змійкою стрілками або свайпами.

## Налаштування

- Відкрийте `Settings` для зміни кольору змійки, теми UI та кольору дошки
- Відкрийте `Difficulty` для вибору швидкості та розміру ігрової дошки

## Примітка

Гра зберігає статистику та налаштування у браузері, тому при наступному відкритті вони будуть відновлені.
